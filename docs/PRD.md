# 사이트 설계도(PRD) — 국제무역사·무역영어 1급 클래스 (사이트 이름 미정)

작성일: 2026-10-17 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
취업 준비생을 위한 국제무역사 1급·무역영어 1급 자격증 취득 강의(개인 대상 클래스).

## 2. 손님
- 누가: 무역·물류 회사 취업을 준비하는 취업 준비생
- 어디서 알고 오나: 블로그·카페, 지인·수강생 소개, 인스타·유튜브

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 수강료
2. 수업 방식·일정
3. 합격 가능성 (비전공·초보도 1급 합격할 수 있는지)
4. 취업 도움 (자격증이 취업에 실제로 도움이 되는지)

## 4. 믿게 할 증거 (실제로 있는 것만)
- 강사 본인 자격·무역 실무 경력: (구체 내용 미정 — 사용자가 알려 주면 그대로 적는다)
- 강의 경력: (구체 내용 미정)
- 실제 합격 사례·후기: 있음 (실제 내용을 받으면 넣는다. 지금은 자리만, 지어내지 않음)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 수강 상담 신청
- 누르면: 문의 폼

## 6. 페이지 구성 (위에서 아래로, 한 장)
1. 첫 화면 — 한 문장 + [수강 상담 신청] 버튼
2. 이런 분께 맞아요 — 취업 준비생, 비전공·초보 안내
3. 과정 소개 — 국제무역사 1급 / 무역영어 1급 (수업 방식·일정·수강료: 미정 자리)
4. 강사 소개 — 자격·실무 경력·강의 경력 (미정 자리)
5. 합격 사례·후기 자리 (실제 내용 받기 전엔 비워 둠)
6. 자주 묻는 질문 — 합격 가능성, 취업 도움, 수강료, 일정
7. 문의 폼 (수강 상담 신청)

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 관심 과정: 국제무역사 1급 / 무역영어 1급 / 둘 다
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: (미정)
- 시간: (미정)
- 위치(온라인/오프라인): (미정)
- 연락 방법: (미정 — 상담 신청 폼은 받음)

## 9. 이번에 넣지 않을 것
- 회원가입·로그인
- 결제
- 블로그
- 알림 메일

## 10. 첫 화면 한 문장 후보
1. 비전공 취업 준비생도, 국제무역사·무역영어 1급까지.
2. 무역 회사 취업, 자격증 1급부터 제대로 준비하세요.
3. 국제무역사 1급·무역영어 1급, 실무 경력 강사와 함께 준비하세요.

## 11. 다음에 할 것
- 수강료·일정·수업 방식·연락 방법 확정해서 8번 채우기
- 강사 자격·경력 구체 내용, 실제 합격 사례·후기 받아서 넣기
- 사이트 이름 정하기
- 회원가입·결제·블로그 (필요해지면)

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 깔끔한 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
